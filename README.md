# Bàn phím Telex (Android)

Bàn phím gõ tiếng Việt kiểu Telex, giao diện giống iPhone.

## Lấy file APK
1. Vào tab **Actions** của repo, chọn workflow **Build APK**.
2. Bấm vào lần chạy mới nhất có dấu tích xanh, kéo xuống mục **Artifacts**.
3. Tải **TelexKeyboard-debug-apk**, giải nén để có `app-debug.apk`, rồi cài lên điện thoại.

## Bật bàn phím
Mở app, bấm "1. Bật bàn phím trong Cài đặt" và bật "Bàn phím Telex".
Sau đó bấm "2. Chọn bàn phím Telex" để chọn làm bàn phím đang dùng.

## Quy tắc Telex
- aa = â, aw = ă, ee = ê, oo = ô, ow = ơ, uw = ư, dd = đ
- Dấu: s = sắc, f = huyền, r = hỏi, x = ngã, j = nặng, z = xóa dấu
- Gõ lặp phím dấu để hủy dấu (ví dụ "ass" ra "as")

## Bảo mật
App không xin quyền INTERNET nên không gửi dữ liệu ra ngoài. Tuy vậy, bàn phím nào cũng thấy những gì bạn gõ, nên chỉ cài bản do chính bạn build.
